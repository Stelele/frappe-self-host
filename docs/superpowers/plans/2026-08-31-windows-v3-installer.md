# BasaPOS v3 Windows Installer — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the broken Inno/WSL-appliance Windows installer with a minimal click-and-run GUI that installs the exact Linux Docker stack inside a WSL2 distro (install + uninstall only).

**Architecture:** CI builds one Frappe image, saves it (plus the 3 stack images) into a WSL2 distro tarball containing Docker Engine; a .NET 10 WinForms installer stitches/verifies the multi-part tarball, imports it via `wsl --import`, and a phased firstboot service inside the distro loads images, creates the site, and generates per-install secrets. Spec: `docs/superpowers/specs/2026-08-31-wsl-docker-parity-installer-design.md` (v2.1).

**Tech Stack:** bash + Docker (appliance), .NET 10 WinForms self-contained single-file (GUI), GitHub Actions (ubuntu + windows runners), WSL2 2.7.11 (pinned MSI).

**Pinned versions (single source of truth for this plan):**

|---|---|
| Ubuntu base | `ubuntu@sha256:2edbbc5dc405e9612ba3584ce95480277e3eb374407b5505fe26f17df77c7dbc` |

### Task 2: Shared compose generation (`gen-compose.sh`)

**Files:**
- Create: `scripts/gen-compose.sh`
- Modify: `scripts/deploy.sh` (reuse the new script; behavior unchanged)

Rationale: the distro must ship a compose file generated by the *same* logic as Linux. `docker compose config` bakes absolute paths, so generation runs inside a staging dir shaped like the distro layout, then a `--rewrite` flag maps the staging prefix onto `/opt/basapos`.

- [ ] **Step 1: Write gen-compose.sh**

```bash
#!/usr/bin/env bash
# Generate the final compose file from the shared frappe_docker chain.
# Usage: gen-compose.sh <out-dir> [--rewrite FROM=TO]
#   <out-dir>  receives compose.final.yaml. The dir MUST have a certs/ sibling
#              (../certs is baked into the config by the selfsigned override).
#   --rewrite  sed the generated file, replacing absolute path prefix FROM with
#              TO (used to map CI staging paths onto in-distro /opt/basapos).
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
REPO_DIR="$(dirname "$SCRIPT_DIR")"
ENV_FILE="$REPO_DIR/.env"
COMPOSE_DIR="$REPO_DIR/frappe_docker"

OUT_DIR=""
REWRITE=""
while [ $# -gt 0 ]; do
  case "$1" in
    --rewrite) REWRITE="$2"; shift 2 ;;
    *) OUT_DIR="$1"; shift ;;
  esac
done
[ -n "$OUT_DIR" ] || { echo "usage: $0 <out-dir> [--rewrite FROM=TO]"; exit 1; }
[ -f "$ENV_FILE" ] || { echo "ERROR: .env not found at $ENV_FILE"; exit 1; }

OFFLINE=""
grep -q '^OFFLINE=true' "$ENV_FILE" && OFFLINE=true

SITES_RULE=""
if grep -q '^SITES_RULE=' "$ENV_FILE" 2>/dev/null; then
  SITES_RULE=$(grep '^SITES_RULE=' "$ENV_FILE" | head -1 | cut -d= -f2-)
elif grep -q '^DOMAIN=' "$ENV_FILE" 2>/dev/null; then
  DOMAIN=$(grep '^DOMAIN=' "$ENV_FILE" | cut -d= -f2)
  SITES_RULE="Host(\`$DOMAIN\`)"
fi
[ -n "$SITES_RULE" ] || { echo "ERROR: set DOMAIN or SITES_RULE in .env"; exit 1; }
export SITES_RULE

COMPOSE_FILES="-f compose.yaml -f overrides/compose.mariadb.yaml -f overrides/compose.redis.yaml -f overrides/compose.proxy.yaml"
if [ "$OFFLINE" = true ]; then
  COMPOSE_FILES="$COMPOSE_FILES -f ../overrides/compose.selfsigned.yaml"
else
  COMPOSE_FILES="$COMPOSE_FILES -f overrides/compose.https.yaml"
fi

mkdir -p "$OUT_DIR"
cd "$COMPOSE_DIR"
# --project-directory "$OUT_DIR" makes ../certs resolve relative to the OUTPUT
# dir: Linux (OUT=frappe_docker) → $REPO_DIR/certs (unchanged); distro staging
# (OUT=…/opt/basapos/compose) → certs sibling baked for /opt/basapos rewrite.
# shellcheck disable=SC2086
docker compose --project-directory "$OUT_DIR" --env-file "$ENV_FILE" $COMPOSE_FILES config > "$OUT_DIR/compose.final.yaml"

if [ -n "$REWRITE" ]; then
  FROM="${REWRITE%%=*}"; TO="${REWRITE#*=}"
  sed -i "s|$FROM|$TO|g" "$OUT_DIR/compose.final.yaml"
fi
echo "wrote $OUT_DIR/compose.final.yaml"
```

`appliance/overlay/usr/local/sbin/basapos-firstboot` (executable):

```bash
#!/usr/bin/env bash
# BasaPOS firstboot — phased, crash-safe. One sentinel per phase under
# /var/lib/basapos/firstboot/. A power-cut at ANY point converges on re-run.
set -uo pipefail

B=/opt/basapos
C=$B/compose
STATE=/var/lib/basapos/firstboot
CREDS=/mnt/c/BasaPOS/config
LOG=/var/log/basapos-firstboot.log

log() { echo "$(date -Us) [$1] $2" | tee -a "$LOG" >&2; }
done_phase() { [ -f "$STATE/$1" ]; }
mark() { touch "$STATE/$1"; }
dc() { docker compose --env-file "$C/.env" -f "$C/compose.final.yaml" "$@"; }

mkdir -p "$STATE"
: > /mnt/c/BasaPOS/logs/firstboot.log 2>/dev/null || true

ADMIN_PW=""
[ -r "$CREDS/install-password.txt" ] && ADMIN_PW="$(tr -d '\r\n' < "$CREDS/install-password.txt")"
[ -n "$ADMIN_PW" ] || { log fatal "missing $CREDS/install-password.txt — GUI must write it before import"; exit 1; }

if ! done_phase loaded; then
  log 1 "docker load images.tar"
  docker load -i "$B/images.tar" >>"$LOG" 2>&1 && mark loaded || { log 1 "load failed"; exit 1; }
fi

if ! done_phase env; then
  log 2 "generate DB password + .env"
  DBPW="$(tr -dc A-Za-z0-9 </dev/urandom | head -c 24)"
  sed "s|__GENERATED_AT_FIRSTBOOT__|$DBPW|" "$C/.env.template" > "$C/.env"
  printf 'DB_ROOT_PASSWORD=%s\n' "$DBPW" >> "$CREDS/credentials.txt"
  mark env
fi

if ! done_phase stack; then
  log 3 "start db + cache tiers"
  dc up -d mariadb-db redis-cache redis-queue >>"$LOG" 2>&1 \
    && sleep 15 && mark stack || { log 3 "tier start failed"; exit 1; }
fi

if ! done_phase site; then
  log 4 "new-site basapos.local"
  APPS="$(dc run --rm --no-deps backend sh -c "cat sites/apps.txt | grep -v '^frappe$' | tr '\n' ' '" 2>>"$LOG")"
  [ -n "$APPS" ] || { log 4 "apps.txt unreadable"; exit 1; }
  FLAGS=""
  for a in $APPS; do FLAGS="$FLAGS --install-app $a"; done
  # shellcheck disable=SC2086
  dc run --rm --no-deps backend bench new-site \
    --mariadb-user-host-login-scope=% \
    --db-root-password "$(grep '^DB_ROOT_PASSWORD=' "$CREDS/credentials.txt" | cut -d= -f2)" \
    $FLAGS --admin-password "$ADMIN_PW" basapos.local >>"$LOG" 2>&1 \
  && dc run --rm --no-deps backend bench --site basapos.local migrate >>"$LOG" 2>&1 \
  && dc run --rm --no-deps backend bench --site basapos.local build >>"$LOG" 2>&1 \
  && dc run --rm --no-deps -T backend tar -chf - -C /home/frappe/frappe-bench assets 2>>"$LOG" \
     | dc run --rm --no-deps -T frontend sh -c 'tar -xf - -C /home/frappe/frappe-bench' >>"$LOG" 2>&1 \
  && mark site || { log 4 "site creation failed"; exit 1; }
fi

if ! done_phase cert; then
  log 5 "per-install certificate"
  RAND="$(tr -dc a-z0-9 </dev/urandom | head -c 8)"
  openssl req -x509 -nodes -days 3650 -newkey rsa:2048 \
    -keyout "$B/certs/key.pem" -out "$B/certs/cert.pem" \
    -subj "/CN=basapos-$RAND.local" -addext "subjectAltName=DNS:basapos.local" >>"$LOG" 2>&1
  cp "$B/certs/cert.pem" "$CREDS/basapos.crt"
  cat > "$B/certs/dynamic.yml" <<'EOF'
tls:
  certificates:
    - certFile: /opt/basapos/certs/cert.pem
      keyFile: /opt/basapos/certs/key.pem
EOF
  mark cert
fi

if ! done_phase booted; then
  log 6 "full stack up --wait"
  dc up -d --wait >>"$LOG" 2>&1 && mark booted || { log 6 "stack failed to come up"; exit 1; }
fi

if ! done_phase done; then
  log 7 "cleanup images.tar"
  rm -f "$B/images.tar"
  mark done
fi

log done "firstboot complete"
```

```bash
#!/usr/bin/env bash
# Daily backup: bench --with-files → copy OUT to Windows; keep last 7.
set -uo pipefail
C=/opt/basapos/compose
DEST=/mnt/c/BasaPOS/backups
TS=$(date +%Y%m%d_%H%M%S)
KEEP=7
LOG=/var/log/basapos-backup.log

log() { echo "$(date -Us) $*" >> "$LOG"; }

AVAIL_KB=$(df --output=avail /mnt/c 2>/dev/null | tail -1)
[ "${AVAIL_KB:-0}" -lt 5242880 ] && { log "skip: <5GB free on /mnt/c"; exit 0; }

mkdir -p "$DEST"
docker compose --env-file "$C/.env" -f "$C/compose.final.yaml" exec -T backend \
  bench --site basapos.local backup --with-files \
  --backup-path "/home/frappe/frappe-bench/backups/$TS" >>"$LOG" 2>&1 || { log "bench backup failed"; exit 1; }

docker compose --env-file "$C/.env" -f "$C/compose.final.yaml" cp \
  "backend:/home/frappe/frappe-bench/backups/$TS" "$DEST/$TS" >>"$LOG" 2>&1 \
  && docker compose --env-file "$C/.env" -f "$C/compose.final.yaml" exec -T backend \
      rm -rf "/home/frappe/frappe-bench/backups/$TS" >>"$LOG" 2>&1 || { log "copy-out failed"; exit 1; }

ls -1dt "$DEST"/20* 2>/dev/null | tail -n +$((KEEP + 1)) | xargs -r rm -rf
log "backup ok: $DEST/$TS"
```

```bash
#!/usr/bin/env bash
# v3 pipeline: ONE image build → save 4 stack images → distro build →
# export → gzip → split → SHA256SUMS. Disk-budgeted for CI runners.
set -euo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
cd "$ROOT"

IMAGE_TAG=basapos:16
DISTRO_TAG=basapos-distro:16
OUT_DIR=appliance/dist
PART_SIZE=1900m
STAGE="$(mktemp -d)"
trap 'rm -rf "$STAGE"' EXIT
mkdir -p "$OUT_DIR"

echo "== 1/6 build frappe image (ONE build — parity by construction) =="
CACHE_BUST="$(sha256sum apps.json | cut -d' ' -f1)"
docker build \
  --build-arg=FRAPPE_PATH=https://github.com/frappe/frappe \
  --build-arg=FRAPPE_BRANCH=version-16 \
  --build-arg=CACHE_BUST="$CACHE_BUST" \
  --secret=id=apps_json,src=apps.json \
  --tag="$IMAGE_TAG" \
  --file=frappe_docker/images/layered/Containerfile frappe_docker

echo "== 2/6 save images.tar (4 pinned stack images) =="
docker pull -q mariadb:11.8
docker pull -q redis:8.6-alpine
docker pull -q traefik:v3.6
docker save "$IMAGE_TAG" mariadb:11.8 redis:8.6-alpine traefik:v3.6 \
  -o "$STAGE/images.tar"
docker image inspect "$IMAGE_TAG" --format '{{index .RepoDigests 0}}' > "$STAGE/image-digest.txt" 2>/dev/null \
  || docker image inspect "$IMAGE_TAG" --format '{{.Id}}' > "$STAGE/image-digest.txt"

ENV_BACKUP="$(mktemp)"; cp .env "$ENV_BACKUP" 2>/dev/null || true
cp .env.snapshot .env
```

`setup-gui/Install/WslRunner.cs` — every external process goes through `Run()`: timeout, no window, UTF-16-safe output decode (read stdout to end BEFORE WaitForExit — v2 lesson), `CreateNoWindow`:

```csharp
using System.Diagnostics;

namespace BasaPOS.Setup.Install;

public sealed record ProcResult(int ExitCode, string Output, string Error);

public static class WslRunner
{
    public static ProcResult Run(string fileName, string arguments, int timeoutSeconds = 600,
        Action<string>? onLine = null)
    {
        var psi = new ProcessStartInfo
        {
            FileName = fileName,
            Arguments = arguments,
            UseShellExecute = false,
            CreateNoWindow = true,
            RedirectStandardOutput = true,
            RedirectStandardError = true,
            StandardOutputEncoding = System.Text.Encoding.Unicode,
            StandardErrorEncoding = System.Text.Encoding.Unicode,
        };
        using var p = Process.Start(psi)
            ?? throw new InvalidOperationException($"failed to start {fileName}");
        var outTask = p.StandardOutput.ReadToEndAsync();
        var errTask = p.StandardError.ReadToEndAsync();
        if (!p.WaitForExit(timeoutSeconds * 1000))
        {
            p.Kill(entireProcessTree: true);
            throw new TimeoutException($"{fileName} timed out after {timeoutSeconds}s");
        }
        // v2 lesson: WaitForExit() again after stream read so buffers flush
        p.WaitForExit();
        var output = outTask.Result;
        var error = errTask.Result;
        if (onLine != null)
            foreach (var line in output.Split('\n', StringSplitOptions.RemoveEmptyEntries))
                onLine(line.TrimEnd('\r'));
        return new ProcResult(p.ExitCode, output, error);
    }

    public static ProcResult Wsl(string arguments, int timeoutSeconds = 600,
        Action<string>? onLine = null) =>
        Run(Environment.SystemDirectory + @"\wsl.exe", arguments, timeoutSeconds, onLine);
}
```

```csharp
    {
        status("Checking WSL…");
        try { WslRunner.Wsl("--status", 30); status("WSL: present"); return; }
        catch (Exception) { /* not installed */ }

        status("Enabling VirtualMachinePlatform + WSL features…");
        var r = WslRunner.RunAnsi("dism.exe",
            "/online /enable-feature /featurename:VirtualMachinePlatform /all /norestart", 600);
        if (r.ExitCode != 0 && r.ExitCode != 3010) // 3010 = success, reboot required
            throw new InvalidOperationException($"dism failed ({r.ExitCode}): {r.Error}");
        var r2 = WslRunner.RunAnsi("dism.exe",
            "/online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart", 600);
        if (r2.ExitCode != 0 && r2.ExitCode != 3010)
            throw new InvalidOperationException($"dism failed ({r2.ExitCode}): {r2.Error}");

        var msi = Path.Combine(payloadDir, "wsl.msi");
        if (!File.Exists(msi)) throw new InvalidOperationException($"wsl.msi missing in payload: {msi}");
        status("Installing pinned WSL 2.7.11…");
```

```csharp
using System.Security.Cryptography;

namespace BasaPOS.Setup.Install;

public static class PartStitcher
{
    public static string[] OrderedParts(string payloadDir) =>
        Directory.GetFiles(payloadDir, "basapos-distro.tar.part-*").OrderBy(p => p, StringComparer.Ordinal).ToArray();

    public static string StitchAndVerify(string payloadDir, Action<int> progress)
    {
        var parts = OrderedParts(payloadDir);
        if (parts.Length == 0)
            throw new InvalidOperationException("no payload parts found");

        var sums = ParseSums(Path.Combine(payloadDir, "SHA256SUMS"));
        var target = Path.Combine(Path.GetTempPath(), "basapos-distro.tar.gz");
        using (var outStream = new FileStream(target, FileMode.Create, FileAccess.Write, FileShare.None, 1 << 20))
            for (int i = 0; i < parts.Length; i++)
            {
                using var part = File.OpenRead(parts[i]);
                part.CopyTo(outStream);
                progress((i + 1) * 90 / (parts.Length + 1));
            }

        progress(91);
        using var sha = SHA256.Create();
        using (var fs = File.OpenRead(target))
        {
            var hash = Convert.ToHexString(sha.ComputeHash(fs)).ToLowerInvariant();
            var expected = sums["basapos-distro.tar.gz"];
            if (hash != expected)
                throw new InvalidOperationException(
                    $"Payload checksum mismatch.\nExpected {expected}\nGot      {hash}\nRe-copy the USB payload.");
        }
        progress(95);
        return target;
    }

    internal static Dictionary<string, string> ParseSums(string path)
    {
        var d = new Dictionary<string, string>();
        foreach (var line in File.ReadAllLines(path))
        {
            var bits = line.Split(new[] { ' ', '\t' }, 2, StringSplitOptions.RemoveEmptyEntries);
            if (bits.Length == 2) d[bits[1].Trim()] = bits[0].Trim().ToLowerInvariant();
        }
        return d;
    }
}
```

```csharp
namespace BasaPOS.Setup.Install;

public static class HostsFile
{
    const string HostsPath = @"C:\Windows\System32\drivers\etc\hosts";
    static readonly string Entry = $"127.0.0.1 {Paths.Domain}";

    public static bool HasEntry(string hostsContent) =>
        hostsContent.Split('\n', StringSplitOptions.RemoveEmptyEntries)
            .Select(l => l.Trim())
            .Any(l => l.Equals(Entry, StringComparison.OrdinalIgnoreCase));

    public static void Ensure()
    {
        var content = File.ReadAllText(HostsPath);
        if (HasEntry(content)) return;
        File.AppendAllText(HostsPath, $"\n{Entry}\n");
    }

    public static void Remove()
    {
        var lines = File.ReadAllLines(HostsPath)
            .Where(l => !l.Trim().Equals(Entry, StringComparison.OrdinalIgnoreCase));
        File.WriteAllLines(HostsPath, lines);
    }
}
```

```csharp
namespace BasaPOS.Setup.Install;

public static class WslConfig
{
    static readonly string Path_ = Path.Combine(
        Environment.GetFolderPath(Environment.SpecialFolder.UserProfile), ".wslconfig");
    const string Begin = "# --- BasaPOS (managed) ---";

    public static string Render(long memoryBytes) =>
        $"{Begin}\n[wsl2]\nvmIdleTimeout=-1\nmemory={memoryBytes / (1024L * 1024 * 1024)}GB\n# --- end BasaPOS ---\n";

    public static void Write(long memoryBytes)
    {
        var existing = File.Exists(Path_) ? File.ReadAllText(Path_) : "";
        var block = Render(memoryBytes);
        if (existing.Contains(Begin))
            existing = System.Text.RegularExpressions.Regex.Replace(
                existing, RegexEscape(Begin) + @".*?--- end BasaPOS ---\r?\n?", "", RegexOptions.Singleline);
        File.WriteAllText(Path_, existing.TrimEnd() + "\n" + block);
    }

    public static void RemoveManagedBlock()
    {
        if (!File.Exists(Path_)) return;
        var existing = File.ReadAllText(Path_);
        var cleaned = System.Text.RegularExpressions.Regex.Replace(
            existing, RegexEscape(Begin) + @".*?--- end BasaPOS ---\r?\n?", "", RegexOptions.Singleline);
        if (cleaned.Trim().Length == 0) File.Delete(Path_);
        else File.WriteAllText(Path_, cleaned);
    }

    static string RegexEscape(string s) =>
        System.Text.RegularExpressions.Regex.Escape(s);
}
```

```csharp
namespace BasaPOS.Setup.Install;

public static class CertTrust
{
    public static void Trust(string certFile)
    {
        using var cert = new X509Certificate2(certFile);
        using var store = new X509Store(StoreName.Root, StoreLocation.LocalMachine);
        store.Open(OpenFlags.ReadWrite);
        store.Remove(cert);   // idempotent replace (unique per-install CN)
        store.Add(cert);
    }

    public static void UntrustAllBasaPOS()
    {
        using var store = new X509Store(StoreName.Root, StoreLocation.LocalMachine);
        store.Open(OpenFlags.ReadWrite);
        foreach (var c in store.Certificates.Find(X509FindType.FindBySubjectName,
                     "basapos", false))
            if (c.Subject.Contains("basapos", StringComparison.OrdinalIgnoreCase))
                store.Remove(c);
    }
}
```

```csharp
using System.Net;
using System.Net.Http;
using System.Security.Cryptography.X509Certificates;

namespace BasaPOS.Setup.Install;

public static class HealthPoller
{
    public static async Task<bool> WaitHealthy(Action<string> status, int maxMinutes = 15)
    {
        string? pinnedThumbprint = null;
        var certFile = Path.Combine(Paths.ConfigDir, "basapos.crt");
        if (File.Exists(certFile))
            pinnedThumbprint = new X509Certificate2(certFile).Thumbprint;

        using var handler = new HttpClientHandler
        {
            ServerCertificateCustomValidationCallback =
                (msg, cert, _, _) => cert is null ||
                    (pinnedThumbprint is not null && cert.Thumbprint == pinnedThumbprint)
        };
        using var http = new HttpClient(handler) { Timeout = TimeSpan.FromSeconds(10) };

        var deadline = DateTime.UtcNow.AddMinutes(maxMinutes);
        int attempt = 0;
        while (DateTime.UtcNow < deadline)
        {
            attempt++;
            try
            {
                var r = await http.GetAsync(Paths.SiteUrl + "/api/method/ping");
                if (r.IsSuccessStatusCode) { status($"Healthy after {attempt} polls."); return true; }
            }
            catch { /* not up yet */ }

            if (attempt % 6 == 0)
            {
                // inside-WSL fallback check (v2 lesson: Windows-side polling can lie)
                var inWsl = WslRunner.Wsl(
                    $"-d {Paths.DistroName} -- curl -sk -o /dev/null -w %{{http_code}} https://localhost/api/method/ping",
                    30);
                if (inWsl.Output.Trim().EndsWith("200")) { status("Healthy (in-WSL check)."); return true; }
            }
            status($"Waiting for site… (poll {attempt})");
            await Task.Delay(TimeSpan.FromSeconds(10));
        }
        return false;
    }
}
```

```markdown
# BasaPOS on Windows — Tech Runbook

## Install (fresh machine)
1. BIOS: enable virtualization (VT-x/AMD-V). `systeminfo` → Hyper-V line must say "yes".

    wsl -d BasaPOS --exec docker compose --env-file /opt/basapos/compose/.env -f /opt/basapos/compose/compose.final.yaml exec -T backend bench --site basapos.local restore --with-files --admin-password <NEWPW> /home/frappe/frappe-bench/backups/<LATEST>

    wsl -d BasaPOS -u root -- systemctl start basapos-backup.service
```
